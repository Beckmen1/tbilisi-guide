# თბილისის გიდი

ერთგვერდიანი ვებსაიტი თბილისის შესახებ. პროექტი შესრულებულია Skillwill-ის Front-end პროგრამის პრაქტიკული დავალების (06.1.1.9) ფარგლებში.

## პროექტის მიზანი

შეიქმნას სემანტიკური, რესპონსიული და ინტერაქტიული ვებგვერდი, რომელიც სტუმარს აცნობს თბილისის ისტორიას, ღირსშესანიშნაობებსა და პოპულარულ უბნებს.

## ტექნოლოგიები

| ტექნოლოგია | გამოყენება |
|---|---|
| HTML5 | სემანტიკური მარკირება (`header`, `nav`, `main`, `section`, `article`, `figure`, `footer`) |
| CSS3 | CSS ცვლადები, Flexbox, Grid, media queries, ანიმაციები |
| JavaScript (ES6) | მობილური მენიუ, სლაიდერი, ფორმის ვალიდაცია |
| Git / GitHub | ვერსიების კონტროლი, ლოგიკური კომიტები |

## ფუნქციონალი

- **ნავიგაცია:** sticky ჰედერი; 768px-ზე ქვემოთ გადადის ბურგერ-მენიუში (`aria-expanded` ატრიბუტით).
- **სლაიდერი:** 4 სლაიდი, წინა/შემდეგი ღილაკები, წერტილები, ავტომატური გადასვლა 5 წამში, პაუზა მაუსის მიტანისას, მართვა კლავიატურის ისრებით.
- **კონტაქტის ფორმა:** სახელის, ელფოსტისა და შეტყობინების ვალიდაცია; შეცდომის ტექსტი ველის ქვეშ; წარმატების შეტყობინება.
- **რესპონსივობა:** დესკტოპი, პლანშეტი (≤900px) და მობილური (≤768px). ბარათები `auto-fit` Grid-ით ეწყობა.

## ოპტიმიზაცია

- სკრიპტი იტვირთება `defer` ატრიბუტით, ამიტომ არ აბლოკავს გვერდის ჩატვირთვას.
- სურათების ნაცვლად გამოყენებულია CSS გრადიენტები, ამიტომ დამატებითი HTTP მოთხოვნები არ არის.
- საერთო მნიშვნელობები (ფერები, რადიუსი) CSS ცვლადებშია, კოდი არ მეორდება.
- დამატებულია `meta description` და `theme-color`.
- `prefers-reduced-motion` მხარდაჭერა ანიმაციებისთვის.
- ინტერაქტიულ ელემენტებს აქვთ `aria-label` და `aria-expanded` ატრიბუტები.

## ტესტირება

შემოწმდა Chromium-ში 1280px და 390px სიგანეზე:

- სლაიდერი გადადის შემდეგ სლაიდზე ღილაკით;
- ცარიელი ფორმა აჩვენებს სამ შეცდომას, სწორად შევსებული — წარმატების შეტყობინებას;
- მობილურზე მენიუ იხსნება ბურგერ-ღილაკით;
- გვერდს არ აქვს ჰორიზონტალური სქროლი მობილურზე;
- JavaScript-ის შეცდომები კონსოლში არ ფიქსირდება.
